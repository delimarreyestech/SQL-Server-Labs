# SQL Server Labs

A collection of practical SQL Server labs focused on T-SQL, query optimization, database development, and data engineering.

This repository explores SQL Server features, query patterns, and data-processing techniques through reproducible examples and real-world-oriented scenarios.

## Areas of Focus

- **T-SQL & Query Patterns:** Set-based operations, window functions, advanced queries, and SQL Server built-in functions.
- **Query Performance:** Execution plans, indexing strategies, query tuning, and performance analysis.
- **Data Engineering:** Data transformations, incremental processing, data quality, and ETL/ELT patterns.
- **Data Warehousing:** Dimensional modeling, date dimensions, and analytical data structures.

## Labs

| Lab | Topic | Description |
|---|---|---|
| 01 | [Finding Missing Values with GENERATE_SERIES()](Query-Patterns/Generate-Series/) | Identify missing integers using set-based operations and dynamic boundaries. |
| 02 | [Building a Date Dimension with GENERATE_SERIES()](Data-Warehousing/Date-Dimension/) | Generate continuous date sequences and build a calendar-based Date Dimension. |


## Environment

Labs may require different SQL Server versions and database compatibility levels. Specific requirements are documented within each lab.
